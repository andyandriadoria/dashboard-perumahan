Model Integrasi Dashboard Perumahan ke SIRUMAH

Dashboard perumahan eksisting diposisikan sebagai Modul Data Perumahan dan PSU dalam SIRUMAH. Data ini menjadi basis awal untuk mendukung prinsip Satu Data, khususnya terkait perumahan formal, rumah subsidi/komersil, status penyerahan PSU, RTH, jalan lingkungan, titik rawan genangan, dan sebaran lokasi perumahan.

Posisi dalam SIRUMAH

  • Satu Data: data perumahan, unit site plan, terbangun, terhuni, status PSU, koordinat, dan catatan teknis.
  • Satu Layanan: data menjadi rujukan untuk layanan informasi perumahan, pengaduan PSU, dan konsultasi pengembang.
  • Satu Kolaborasi: daftar perumahan dan pengembang menjadi bahan koordinasi dengan pengembang, bank, CSR, BAZNAS, dan perangkat daerah terkait.
  • Satu Monitoring: status PSU, RTH, jalan, dan progress unit dipantau secara berkala melalui dashboard.

Catatan Penggunaan

  • Data ini dapat digunakan untuk kerja internal Dinas Perkim dan bahan laporan kepada pimpinan.
  • Untuk versi publik, sebaiknya data pribadi seperti nama direktur/pelaksana disembunyikan.
  • Data tanpa koordinat tetap masuk dalam rekap, tetapi tidak muncul pada peta.
  • Nilai skor prioritas bersifat alat bantu awal dan tetap perlu verifikasi lapangan.

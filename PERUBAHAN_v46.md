# Perubahan SIRUMAH v46

## Sidebar

- Menambahkan kartu identitas pengelola di bagian bawah sidebar.
- Isi kartu: Dinas Perumahan dan Kawasan Permukiman Kota Pangkalpinang, informasi pemutakhiran data, serta label SIRUMAH v1.0 · 2026.
- Tidak menambahkan teks hak cipta di bagian paling bawah.
- Sidebar dibuat sebagai flex column agar kartu berada di bawah saat ruang layar mencukupi dan tetap dapat digulir pada layar pendek.

## Beranda

- Menghapus kartu Status Dashboard beserta pemanggilan render-nya.
- KPI dan analisis Beranda kini langsung tampil setelah banner mode akses.

## Fitur lain

- Integrasi Excel, Google Sheets, Mode Publik/Internal, menu, filter, laporan, dan fitur v45 tetap dipertahankan.
